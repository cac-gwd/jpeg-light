# JPEG Light

JPEGの画質をスライダーで調整し、保存前に元の容量と圧縮後の実際の容量を比較するツールです。

## 使い方

1. `index.html` をブラウザーで開くか、GitHub Pagesのサイトにアクセスします。
2. JPEG画像を選択するか、画面にドロップします。
3. 画質スライダーを調整し、容量とプレビューを確認します。
4. 「JPEGを保存」で別ファイルとしてダウンロードします。

画像はブラウザー内で処理され、サーバーへアップロードされません。元のファイルとピクセル数は維持されます。出力時にEXIFなどの付加情報は削除されます。

## 構成・公開

ビルドや外部ライブラリは不要です。HTML、CSS、JavaScriptとブラウザーのCanvas APIで動作します。

GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `/ (root)`。

## 制限

- JPEG形式のみ対応。5,000万画素を超える画像は対象外です。
- 再圧縮により容量が元画像より増えることがあります。
- 品質値と容量の関係は画像やブラウザーに依存し、厳密に単調ではありません。
- ブラウザーによって圧縮結果や色の再現に差が生じる場合があります。

JavaScriptの構文確認済み。ブラウザーでの画像選択・圧縮・保存の一連の動作確認は未実施です。
